# Birthday Surprise Website 🎂💖

A 12-section interactive birthday website recreated from the supplied screen recording style.

## Features
- 12 full-screen sections
- Dark starry background + pink/purple glow
- Playful Yes/No interaction
- Click-to-blow birthday cake
- Click-to-cut cake
- Large editable photo gallery
- Local photo upload in the browser
- Balloon popping game
- Interactive wishes
- Timeline section
- Personal letter
- Click-to-open gift
- Final confetti celebration
- Keyboard + mouse-wheel navigation
- Mobile responsive
- No framework/build step required

## Edit the website
Open `script.js` and change:

```js
const CONFIG = {
  name: 'Jana',
  photos: ['1.jpg','2.jpg','3.jpg']
};
```

Put your real images inside `assets/photos/` and update the filenames in `CONFIG.photos`.

You can also directly edit all text in `index.html`.

## Run locally
Just double-click `index.html`, or use VS Code Live Server.

## GitHub Pages
Upload the entire folder to a GitHub repository, then enable **Settings → Pages → Deploy from branch** and choose the `main` branch / root folder.
